2025–26 Bioinformatics Paper Flaw Analyses

This audit was conducted using natural-joints — independent code & data audits of published research papers, applying semantic data-layer enrichment plus multi-agent code/honesty/facts review to detect findings where the script source, the deposited data, and the paper text are in tension.

This repository collects flaw analyses of recent (2025–26) high-profile bioinformatics papers where the audit surfaces convincing real bugs — bugs in the committed code or contradictions between paper text and what the public artifacts show. The audits restrict to findings where "the public deposit is a subset, not the production cohort" is not a credible defense, because the finding lives in the script source, in the paper text itself, or in methodological choices independent of which patients are in the data.

DOI 10.1038/s41588-025-02233-y · PMID 40551015 · GitHub macintyrelab/Thompson2025_ChemoResistancePrediction

Verdict. Headline hazard ratios reproduce from the committed code+data; the criticisms are about what those numbers mean.

  • 25 verified findings, all novel as of audit date.
  • 5 MAJOR-impact findings, including a published HR=20.020 (Fig 2c) not derivable from committed code (the script pastes the triple instead of computing it); 5 of 9 main HRs vacate under Bonferroni; RECIST progression coded as censoring=0 shifts breast taxane HR by +66%, breast anthra HR by −36%; NaN-CX patients get deterministic prediction labels by file membership.
  • 10 MODERATE findings, including the abstract's "stratified Cox by age" applying to only 1 of 6 headline cohorts; IPTW achieving balance for only 2 of 4 cohorts; Capecitabine omitted from named SoC (70%+ of control arm); Olaparib named in Methods but has 0 occurrences in cohort.

BREAKS HEADLINE Aung et al., Nature Genetics 2025 — "Spatial signatures for predicting immunotherapy outcomes using multi-omics in non-small cell lung cancer."

DOI 10.1038/s41588-025-02351-7 · PMID 41073787 · GitHub tznaung/NSCLC_SpatialOmics

Verdict. Two of the Yale-cohort headline hazard ratios collapse from "significant" to "not significant" when a one-character bug in the committed R source is corrected.

  • Bug: Surv(as.numeric(time, event)) — as.numeric() silently drops the event indicator, Surv() defaults to "all events observed." Repeated 11 times across cell-fraction scripts.
  • Yale resistance signature: paper HR 3.8 (p=0.004) → corrected HR 2.58 (p=0.053). Significance lost.
  • Yale response signature: paper HR 0.4 (p=0.019) → corrected HR 0.30 (p=0.057). Significance lost.
  • Bug surface confined to cell-type fraction scripts; gene-signature (cell-to-gene) HRs use correct Surv(t, e) and are not refuted.

Methodology

Each audit was performed by a 9-agent automated pipeline: 3 blind auditors (code / honesty / facts) working from a clean copy of the data with no semantic enrichment; 3 enriched auditors with full schema enrichment; then 3 summary agents (verifier, novelty-checker, impact-runner). All findings shown were either (a) verified by independent re-running of the published code against the deposited data, (b) verified by reading the paper text against the script source, or (c) verified by structural proof from code + data values.

Findings that could be excused by "the deposited data is a stale subset" — cohort-size mismatches between deposited supplementary tables, patients flagged inconsistently across files, etc. — are omitted from these reports. Raw per-agent transcripts and the full superset of findings are available in each paper's audit directory.
