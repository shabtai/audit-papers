This audit was conducted using natural-joints — independent code & data audits of published research papers, applying semantic data-layer enrichment plus multi-agent code/honesty/facts review to detect findings where the script source, the deposited data, and the paper text are in tension.

This repository collects flaw analyses of recent (2025–26) high-profile bioinformatics papers where the audit surfaces convincing real bugs — bugs in the committed code or contradictions between paper text and what the public artifacts show. The audits restrict to findings where "the public deposit is a subset, not the production cohort" is not a credible defense, because the finding lives in the script source, in the paper text itself, or in methodological choices independent of which patients are in the data.

★ Featured: The top 4 most impressive bugs across both papers — detailed deep-dive on the bugs that combine highest impact with most striking root-cause structure.
  1. Aung's validate_finalSigs_pStroma_RNA.R outputs HR=1.1, p=0.6 — abstract claims HR=0.38 for the same comparison (released code does not reproduce abstract).

PARTIAL Thompson et al., Nature Genetics 2025 — "Predicting resistance to chemotherapy using chromosomal instability signatures."

DOI 10.1038/s41588-025-02233-y · PMID 40551015 · GitHub macintyrelab/Thompson2025_ChemoResistancePrediction

Verdict. Headline hazard ratios reproduce from the committed code+data; the criticisms are about what those numbers mean.

  • 25 verified findings, all novel as of audit date.
  • 5 MAJOR-impact findings, including a published HR=20.020 (Fig 2c) not derivable from committed code (the script pastes the triple instead of computing it); 5 of 9 main HRs vacate under Bonferroni; RECIST progression coded as censoring=0 shifts breast taxane HR by +66%, breast anthra HR by −36%; NaN-CX patients get deterministic prediction labels by file membership.
  • 10 MODERATE findings, including the abstract's "stratified Cox by age" applying to only 1 of 6 headline cohorts; IPTW achieving balance for only 2 of 4 cohorts; Capecitabine omitted from named SoC (70%+ of control arm); Olaparib named in Methods but has 0 occurrences in cohort.

BREAKS HEADLINE Aung et al., Nature Genetics 2025 — "Spatial signatures for predicting immunotherapy outcomes using multi-omics in non-small cell lung cancer."

DOI 10.1038/s41588-025-02351-7 · PMID 41073787 · GitHub tznaung/NSCLC_SpatialOmics

Verdict. Of 8 hazard ratios named in the abstract, at least 5 either collapse to non-significance under bug correction, are unreproducible from the released artifact, or are products of post-hoc statistical choices (one-sided p-values, selection on held-out HR, sign-constrained LASSO).

  • 37 verified findings (1 published directly + 36 from the full audit), all novel as of audit date.
  • 12 MAJOR-impact findings, including: the released `validate_finalSigs_pStroma_RNA.R` script outputs HR=1.1, p=0.6 while the abstract claims HR=0.38 for the same comparison; the Greek validation cohort (n=79) has zero code in the repository; cell-to-gene signatures are picked from analysis runs filtered by their held-out test HR (textbook circular validation); `lower.limits=0`/`upper.limits=0` in LASSO forces the resistance signature to be non-negative and response to be non-positive — direction set by keyword, not data; `Surv(as.numeric(time, event))` at 11 sites drops the censoring vector; orphan coefficient files mean the published cell-to-gene HR=5.1 cannot be regenerated end-to-end from the artifact.
  • 14 MODERATE-impact findings, including: Yale cohort is n=29-31 patients, not n=41 as abstract claims; `"Censored"` ≡ `"Status"` ≡ OS in deposited CSVs; Tumor file uses days/month=22.16, Stroma file uses 30.44 — so KM curves from Tumor file are on a fictional ~37%-compressed timescale; cell-typing `ffill` priority labels Ki67+ FOXP3+ CD4 cells as `Proliferating_Tumour` (the lead cell type in the resistance signature).
  • This audit was originally published with just the single Surv() finding from direct code reading; the multi-agent pipeline was run later and found the additional 36.

Verification standard

Every finding shown was independently verified by one of: (a) re-running the published code against the deposited data, (b) reading the paper text against the script source, or (c) structural proof from code + data values.

Findings that could be excused by "the deposited data is a stale subset" — cohort-size mismatches between deposited supplementary tables, patients flagged inconsistently across files, etc. — are omitted from these reports.
