This audit was conducted using natural-joints — independent code & data audits of published research papers, applying direct code review plus multi-agent code/honesty/facts review.

Paper: Aung TN, Monkman J, Warrell J, et al. Nat Genet (2025). 10.1038/s41588-025-02351-7 · PMID 41073787 · PMCID PMC12513832.

Methodology applied to this paper: direct code review (Surv typo finding, published earlier) PLUS subsequent multi-agent audit team (3 blind code/honesty/facts + verifier + novelty-checker + impact-runner). Semantic enrichment was attempted but did not complete — the enricher hung at trap-detection and was not used. All audit findings below are from code review and data inspection, not enrichment.

Headline finding. Of 8 hazard ratios named in the paper's abstract, at least 5 either collapse to non-significance under bug correction, are unreproducible from the released artifact, or are products of post-hoc statistical choices (one-sided p-values, selection on the held-out HR, sign-constrained LASSO). The originally-published flaw on this page covered one finding — a Surv(as.numeric(time, event)) typo at 11 sites that drops the censoring vector. The full audit found 36 additional novel findings, several of which are individually more damaging.

The originally-published finding: Surv(as.numeric(time, event))

One-character bug repeated 11 times in lasso_cox_cellFract_* and the gene-LASSO scripts. as.numeric() silently drops extra positional arguments, so the event vector is discarded before Surv() ever sees it; Surv(time) with one argument defaults to "all events observed."

library(survival)
t <- c(10, 20, 30, 40, 50)
e <- c(1,  0,  1,  0,  1)
Surv(as.numeric(t, e))   # 10  20  30  40  50      <-- all events observed
Surv(t, e)               # 10  20+ 30  40+ 50      <-- 20 and 40 censored

This bug alone collapses Yale resistance HR 3.8 (p=0.004) → 2.58 (p=0.053) and Yale response HR 0.4 (p=0.019) → 0.30 (p=0.057). It is documented in detail at the top of the audit log below and was the only finding in the original version of this page.

12 MAJOR-impact findings

1. The Surv bug also infects the cell-fraction Cox models (extension of the published bug to new locations) MAJOR

Sites: lasso_cox_cellFract_tumor_*.R:20,84,128 and lasso_cox_cellFract_stroma_*.R:20,90,138,139. Same pattern as the 11 RNA-LASSO sites but in the scripts that derive the cell-type signatures. This means the published Yale tumor HR=3.8 and Yale stroma HR=0.4 inherit the same event-vector-drop bug.

2. After BH/FDR correction, no cell type is significant MAJOR

The deposited forest CSVs (Univariate_Tumor_471_PFS_2Years_067CP_forest.csv and Stroma equivalent) include a BH-adjusted p column. Every cell type in both forests has BH-adjusted p ≥ 0.15. The three constituents of the resistance signature (Proliferating_Tumour, Granulocytes, Vessels) have BH-adjusted p ≥ 0.83 each. The composite signature p=0.004 only emerges via LASSO selection + sign constraint + binarization + the Surv bug.

3. UQ validation p-values are halved one-sided post-hoc by sign of observed HR MAJOR

Sites: lasso_cox_cellFract_tumor_*.R:173, ..._stroma_*.R:188, validate_finalSigs_CK_RNA.R:140, validate_finalSigs_pStroma_RNA.R:150:

p_value_one_sided <- ifelse(summary(cox)$coefficients[2] > 1,
                            p_value_two_sided / 2,
                            1 - p_value_two_sided / 2)

Direction is picked post-hoc from the observed coefficient sign. Plots annotate this with "Log-Rank-1-sided" for validation and "Log-Rank-2-sided" for discovery. Both abstract validation p-values become two-sided 0.10 (UQ tumor) and 0.072 (UQ stroma) — neither below conventional significance, both 95% CIs cross 1.

4. Cell-to-gene final signatures selected by held-out test-set HR MAJOR

In lasso_CK_RNA_neg_Res_cells_..._finalSig.R:52:

hzrs = read.csv("hzrs_CK_PFS_5Years_3celltypes_resistance_P_G_V_CW_genes.csv")
good_models = which((hzrs$x)>=1.5)         # resistance direction
# mirror in stroma response script:
good_models = which((hzrs$x)<=0.7)         # response direction

hzrs$x is the held-out test-cohort HR from 50 random 80/20 splits (generated by lasso_TrainTest_*). The final signature is built by running gene voting only over splits whose test HR was already in the desired direction. The validation result is the model-selection criterion — textbook circular validation. Genes appearing across these "good" splits are then assembled and re-evaluated on the same Yale cohort.

5. UQ stroma RNA validation: released code emits HR=1.1, p=0.6 — abstract claims HR=0.38 MAJOR

validate_finalSigs_pStroma_RNA.R:157 literal:

label = "HR = 1.1 (0.43-3) \n p = 0.6 (Log-Rank-1-sided) \n cutpoint = tertile"

The script uses Surv(OS_5Years_months, OS_5Years_index) on the UQ_Stroma CSV. Output: HR=1.1, p=0.6. Abstract reports HR=0.38 for the same comparison. The released code does not reproduce the abstract's UQ stroma response HR. Note: a 2-sided p of 0.6 is symmetric — this isn't a sidedness artefact, the released code computes HR=1.1, period.

6. Tumor and Stroma analyses share patients — not 8 independent tests MAJOR

Yale tumor (29 patients) ∩ Yale stroma (31 patients) = 28 in common. UQ tumor (26) ∩ UQ stroma (26) = 26 (full overlap). The 4 cell-type HRs + 6 cell-to-gene HRs the abstract presents as "8 consistent results" are not 8 independent tests — most are recomputations on substantially the same patients with different feature transformations. Bonferroni at family size 8 (α=0.0062) drops every reported p-value except Yale tumor (0.004) and Yale cell-to-gene resistance (0.002) below significance — and both survivors are in-sample LASSO refits.

7. Greek cohort (n=79) entirely absent from repo MAJOR

grep -ri "greek|hellenic|patras|athens|thessaloniki|crete" over the entire repo returns zero hits in any analysis script. The abstract's Greek validation HRs (resistance HR=1.7, response HR=0.56) are not reproducible from the public artifact.

8. Cohort-comparability: Yale = 1st-line pre-Tx Pembro; UQ = post-1st-line Nivo MAJOR

Yale (training): all Biopsy_at_ITX = "Pre", all line_at_ITX = "1", 28/32 on Pembrolizumab. UQ (validation): Biopsy_at_ITX = #N/A for 35/35, 27/35 on Nivolumab, 23/35 ≥ 2nd line. Pre-Tx vs post-Tx biopsies are biologically different (clonal selection under IO). The commented-out filters in the LASSO scripts (Histology %in% c("Squamous"), ImmunoTx %in% c("Nivo")) reveal the authors are aware these are confounders.

9. lower.limits=0 / upper.limits=0 forces directional signatures MAJOR

The LASSO sign constraint lower.limits = 0 (tumor) and upper.limits = 0 (stroma) guarantees the resulting signature is non-negative ("resistance") or non-positive ("response") — direction is set by a keyword, not by the data. Post-LASSO refit then silently drops negative coefficients via coeffs = coeffs[which(coeffs >= 2)] (HR ≥ 7.4 per unit fraction), a hardcoded filter with no rationale.

Verified by re-running: with correct Surv + same sign constraint, Yale tumor signature gives HR=2.18, p=0.105 (not 3.8, p=0.004 as published). Without sign constraint, the signature collapses — no cell type meets the stability threshold.

10. BH-adjusted FDR is commented out across all 4 RNA-LASSO scripts MAJOR

Sites: lasso_TrainTest_CK_RNA_*.R:84-85, lasso_TrainTest_pStroma_RNA_*.R:83-84, lasso_CK_RNA_neg_..._finalSig.R:88-89, lasso_Stroma_RNA_pos_..._finalSig.R:82-83:

#FDR <- p.adjust(response$table$PValue, method="BH")
FDR <- response$table$PValue
...
dex_sel_genes = dex_df[which(dex_df$FDR < 0.05),] # take only genes that have FDR < 0.1

The variable named FDR is the raw edgeR exactTest p-value. The trailing comment also doesn't match the literal threshold. With ~6,000–10,000 genes per split and a raw p < 0.05 gate, ~5% of the genome enters LASSO on chance alone — ~500× more false positives than the paper's "FDR < 0.05" claim implies.

11. Orphan coefficient files: code writes one filename, reads another that doesn't exist MAJOR

lasso_CK_RNA_neg_..._finalSig.R line 243 writes final_coeffs_PFS_5Years_3celltypes_CW_CK_resistance.csv; line 256 reads final_coeffs_PFS_5Years_3celltypes_CK_resistance_0p1.csv (different filename). find over the entire repo returns zero matches for the read filename. Also missing: Yale_firstLine_pre_patients.csv (training-cohort definition file) and every hzrs_*.csv file. The public code cannot be run end-to-end against the public data. The headline training/test HRs are computed off files that are not in the deposit.

12. Cell-typing per-cell z-score (axis=1) destroys marker discrimination; M1/M2 gates on z-scored values MAJOR

PCF_Celltyping.ipynb cells 37, 66, 84, 109 each z-score per cell across markers (axis=1), then cell 86 hardcodes M1 vs M2 gates on those z-scored values at boundary 0.3. Per-cell z-scoring forces every cell to mean-0/SD-1 across its panel — a CD8 cell with high CD8 looks identical to a tumor cell with high pan-CK, because both peak in one channel. The same cell, re-clustered with a different marker panel, would get a different CD163 z-score with no change in true expression. Affects all cell labels → cell-fraction features → headline HRs.

Reproducibility blockers

Three files referenced by the released code are not in the deposit:

  • Yale_firstLine_pre_patients.csv — defines the Yale training cohort
  • final_coeffs_PFS_5Years_3celltypes_*_resistance_0p1.csv — read by signature scripts (different filename than what gets written)
  • hzrs_CK_PFS_5Years_3celltypes_resistance_P_G_V_CW_genes.csv and other hzrs_*.csv — held-out test-cohort HRs from 50 train/test splits

The Greek validation cohort has no code at all in the repo. The public code cannot run end-to-end against the public data — the published cell-to-gene HR=5.1 cannot be regenerated from the artifacts the paper points readers to.

Methodology used for this audit

Honest record of what was applied to this paper:

  1. Direct code review (manual reading of lasso_cox_cellFract_* scripts) found the Surv(as.numeric(time, event)) bug at 11 RNA sites. This was the only finding when the audit page was first published.
  2. Semantic-enricher was attempted but did not complete — the enricher hung at the trap-detection stage on the gene-expression CSVs (which have ~10,000 columns) for several hours without progress. No enrichment artifacts were produced; enrichment did not contribute to any finding on this paper.
  3. Multi-agent audit team was then spawned on the deposited CSVs + code, without enrichment: 3 blind agents (blind-code, blind-honesty, blind-facts) + verifier + novelty-checker + impact-runner. These 6 agents jointly produced the 36 additional findings above. Raw per-agent transcripts are at ~/gits/audit-papers/aung2025-nsclc/.audit/1780318231/raw/.

Novelty: all 36 new findings are NOVEL as of 2026-06-01. Zero GitHub issues, zero PRs, no PubPeer entries, no Nature Genetics errata, no Retraction Watch entries on this paper. The shabtai-published Surv finding is the only prior public commentary.

Audit conducted 2026-06-01. All findings reproducible from the public figshare deposit + the public GitHub repo + the paper text; no access to restricted clinical data was used. Verifier confirmed every priority finding via independent R/Python recomputation. Impact-runner quantified each finding via Path A (fix-and-re-run), Path B (structural proof), or Path C (proxy).
